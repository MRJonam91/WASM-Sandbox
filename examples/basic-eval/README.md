# Basic Evaluation Example

Questa cartella conterrà esempi pratici end-to-end:
1. **Node.js**: Esecuzione di script non fidati con blocco deterministico di loop infinito via fuel metering.
2. **Memory Limit**: Test di cattura `OUT_OF_MEMORY` isolato senza crash del processo host.
3. **Capability Broker**: Esempio di intercettazione e blocco di tentativo di connessione non autorizzata o SSRF.
